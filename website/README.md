# Course Website

هذا المجلد مخصص للموقع الإلكتروني الخاص بالدورة.

البنية الأولية:
- `index.html` — الصفحة الرئيسية.
- `assets/css/` — ملفات التنسيق.
- `assets/js/` — ملفات JavaScript.
- `assets/images/` — الصور والشعارات لاحقًا.

سيتم تطوير الموقع تدريجيًا ليعرض البرنامج، التسجيل، المحاور، الموارد، والمدربين.
